# Sagor Chandra Paul — Portfolio

A personal portfolio website built with plain HTML and CSS. It introduces Sagor Chandra Paul, highlights his computer science background and skills, and presents selected projects, education, certifications, and contact information.

## Features
- Single-page layout with Home, About, Skills, Projects, Education, Certifications, and Contact sections
- Profile image and education-related images
- Responsive styling defined in `style.css`
- Google Fonts (Montserrat)

## Tech Stack
- HTML5
- CSS3

## Project Structure

```text
portfolio-/
├── index.html
├── style.css
├── sa.png
├── sagor.jpeg

```

## Run Locally
No build tools or package installation are required.

1. Clone or download this repository.
2. Open `index.html` in your browser.

For a local development server, you can use the VS Code Live Server extension.

## Customize
- Edit text and sections in `index.html`.
- Change colors, spacing, and responsive styles in `style.css`.
- Replace the image files while keeping the filenames, or update their paths in the HTML.

## Notes
Some project and social links in the page may be placeholders. Replace them with the correct URLs before publishing.
